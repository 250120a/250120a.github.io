# Mini Tic-Tac-Toe (Flutter)

A polished mini Tic-Tac-Toe experience built with Flutter. The app keeps score between rounds, highlights winning lines, and features a Material 3 inspired interface that looks great on phones and tablets.

## Features

- 🧠 Smart gameplay loop with win detection and draw handling.
- 🏆 Persistent scoreboard with quick reset buttons.
- ✨ Animated tiles and highlighted winning combos for extra polish.
- 📱 Responsive layout that scales gracefully across screen sizes.

## Getting Started

1. Ensure you have the [Flutter SDK](https://docs.flutter.dev/get-started/install) installed.
2. From the project root, change into this directory:

   ```bash
   cd flutter_tic_tac_toe
   ```

3. Get the dependencies:

   ```bash
   flutter pub get
   ```

4. Run the app:

   ```bash
   flutter run
   ```

## Project Structure

- `lib/main.dart` – Contains the full Flutter application.
- `pubspec.yaml` – Project metadata and dependencies.

Feel free to tweak the colors, animations, or add AI opponents to extend the experience!
